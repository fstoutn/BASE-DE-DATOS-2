# Repository Overview

Coursework and database scripts for **BASE DE DATOS 2**.

## Structure & Conventions

- **Directory Layout:** Organized by unit and week: `UNIDAD <N>/Semana <M>/` (e.g., `UNIDAD 1/Semana 2/`).
- **Database Engine:** PostgreSQL.
- **File Naming & Extensions:** SQL schema files may lack a `.sql` extension (e.g., `UNIDAD 1/Semana 2/schema`). Inspect file contents directly rather than relying on extension matching.
- **Language & Naming:** All database objects (tables, columns, enums, constraints) and comments are in Spanish.
- **Encoding Note:** Some repository files (e.g., `README.md`) use UTF-16 LE encoding.
